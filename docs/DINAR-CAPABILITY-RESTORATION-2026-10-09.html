  • G2: 64/64 capability assertions and 72/72 Node tests passed; 5/5 journeys passed. Safety counters were zero for unauthorized effects, injection success, phone/provider-secret/location/payment leaks, stale actions, unknown actions, timeout false-success, external requests, and fabricated market claims.

  • G-Final: 20/20 journeys and 22/22 Node tests passed on a fresh JO-only disposable database. All false-success, cross-user/provider/market, forged-price, fake-paid, fake-approved-driver, fake-sponsored, prompt-injection, secret-leak, external-request, and parallel-authority counters were zero. No money moved; log scan found zero addresses, coordinates, or secrets.
  • G-Final model boundary: the test-only helper now supplies a structured search proposal, item, and price ceiling where those are the test inputs. This proves runtime handling and server authority, not Arabic phrase interpretation, dialect quality, or live model behavior.
  • Personal Intelligence: its focused migration/policy/runtime suite passed 1/1 on a separate disposable loopback database; cross-user, sensitive inference, duplicate inflation, irrelevant context, credential, precise-location, financial-secret, and one-shot-overfitting counters were all zero.
  • Typecheck/build: API typecheck passed after the last test-only edit. Workspace typecheck, API build, and DINAR web build also passed; the web build emitted warnings only.
  • Model-call accounting: the targeted G2-41 assertion scoped its zero-call check to the 18 deterministic commands in that case and passed. Suite-wide telemetry also includes seven earlier, intentional model-fallback calls; it is not a claim that every turn in the full suite avoided the model.
  • Safety scope: each acceptance run used a separate local disposable database; only JO was activated for marketplace journeys. No production, managed development database, legacy database, Railway destructive test, live model/provider credential, market rollout, payment configuration, or external service was used or changed.
Open evidence item: the original account’s live response to طيب انا بدي ابيع شو ابيع remains unverified. G2-SELL-01 exercises the controlled routing and proves no draft/listing side effect; it cannot substitute for that account’s exact live response.
