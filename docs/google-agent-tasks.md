# مهام وكيل جوجل — واجهة جاسم

**متى يبدأ:** بعد أن يكتب المالك «اكتمل الإطلاق». قبلها: قراءة وتصميم فقط.
**المراجع:** Claude يراجع كل فرع قبل الدمج. لا شيء يُنشر دون مراجعة وموافقة المالك.

## قواعد ثابتة (لا تُكسر)

1. اعمل على فرع خاص لكل مهمة: `google/<اسم-المهمة>` من `claude/jassim-connect-universal-engine`. لا تدفع إلى فرع الإطلاق ولا تدمج.
2. لا تلمس Production ولا Railway ولا قاعدة بيانات غير محلية، ولا تقرأ أو تكتب أي مفتاح سري.
3. الواجهة فقط: `artifacts/dinar/src/`. أي تغيير في الخادم (`artifacts/api-server`) أو قاعدة البيانات (`lib/db`) أو العقد (`lib/api-spec`) يُطلب من Claude.
4. لا تعدّل الملفات المولّدة (`lib/api-zod`, `lib/api-client-react`) يدويًا.
5. الأسعار والمبالغ والعملة تأتي من الخادم دائمًا؛ الواجهة لا تحسب سعرًا نهائيًا.
6. لا تعرض نجاح عملية (طلب، دفع، موافقة) قبل رد الخادم بنجاح.
7. لا تعرض سوقًا «معتمدًا قانونيًا» إلا إذا كان `legalApprovalStatus === "APPROVED"`.
8. العربية أولًا، اتجاه RTL، تعمل على شاشة 360px، وألوان الوضع الداكن.
9. الشعار المعتمد فقط (`public/brand/`)؛ الاسم «جاسم» وليس «دينار».
10. قبل طلب المراجعة: `pnpm run typecheck` و`pnpm --filter @workspace/dinar run build` ينجحان، مع لقطات شاشة (جوال وحاسوب، فاتح وداكن).

## المهام بالترتيب

| # | المهمة | المطلوب | معيار القبول |
|---|---|---|---|
| 1 | مراجعة الواجهة الحالية | تقرير بالمشاكل: نصوص قديمة، أزرار مكسورة، تباين ضعيف، تخطيط مكسور على الجوال | قائمة مرتبة حسب الخطورة مع لقطات؛ بلا تعديل كود |
| 2 | صفحات التسجيل والدخول | وضوح خطوات Google + كتابة الرقم مرتين، رسائل الخطأ بجانب الحقل الخاطئ، اختيار الدولة الذكي ظاهر | كل خطأ من الخادم يظهر نصه؛ يعمل بلوحة المفاتيح وقارئ الشاشة |
| 3 | واجهة المحادثة | تحسين فقاعات الرسائل، حالة «جاسم يكتب»، بطاقات المتاجر الذكية، الأزرار السريعة | لا تغيير في منطق المحادثة؛ سلس على 360px |
| 4 | صفحة الترحيب والصفحة الرئيسية | تعريف واضح بجاسم، أمثلة لما يمكن طلبه، دعوة للتسجيل | تحميل أول أقل من 3 ثوانٍ على 4G |
| 5 | حالة السوق للمستخدم | شارة صغيرة: «تشغيل تقني — الدفع نقدًا فقط» للأسواق `PRE_LEGAL`، دون ادعاء اعتماد قانوني | النص مأخوذ من `operationMode` و`legalApprovalStatus` فقط |
| 6 | لوحة الإدارة | توحيد شكل صفحات الإدارة، تحسين صفحة «الأسواق العربية» (بحث، فلترة حسب الحالة) | الحالتان التقنية والقانونية تبقيان منفصلتين بصريًا |
| 7 | صفحة الاشتراكات (Go / Pro / Business) | عرض الخطط والأسعار من الخادم، رسالة واضحة حين يكون الدفع غير متاح في الدولة | لا أسعار مكتوبة في الكود؛ زر الدفع معطّل حين يرفض الخادم |
| 8 | إعدادات الإعلانات الذكية | تصميم صفحة «لماذا أرى هذا الإعلان» وإعدادات التخصيص (فرع `claude/jassim-smart-ads`) | تصميم فقط حتى يُدمج الفرع |
| 9 | إمكانية الوصول | فحص WCAG AA: التباين، التركيز، الأسماء للأزرار، أحجام اللمس | لا أخطاء حرجة في الفحص |
| 10 | الأداء | تقليل حجم الحزمة الأولى، تحميل الصور كسولًا | تقرير قبل/بعد بالأرقام |

## طريقة التسليم لكل مهمة

1. فرع `google/<اسم-المهمة>` مدفوع إلى GitHub.
2. وصف قصير: ما تغيّر، لماذا، الملفات، لقطات الشاشة، نتيجة typecheck والبناء.
3. يرسل المالك الرابط إلى Claude للمراجعة. Claude يدمج بعد الموافقة أو يعيد الملاحظات.

## ما لا يفعله الوكيل

- لا مدفوعات، لا Whop، لا مفاتيح، لا DNS، لا موافقات قانونية، لا تفعيل أسواق.
- لا حذف ميزات أو اختبارات قائمة.
- لا مكتبات جديدة دون موافقة Claude.
