# DINAR — قرارات المالك 2026-10-30 (المواصفة الحالية للمنتج)

**الحالة:** متطلبات عمل اعتمدها المالك مبدئيًا. **ليست موافقات تنظيمية نهائية.** تتقدم هذه القرارات على أي افتراض تاريخي يتعارض معها، وعلى وثائق `docs/dinar-next/` الأقدم.

**المصدر:** «DINAR NEXT — CLAUDE CODE FINAL DEVELOPMENT MANDATE، OWNER DECISIONS v2026-10-30».

**قراءة الجدول:**
- **مقرر:** ينفَّذ في الكود.
- **مبدئي:** ينفَّذ قابلًا للضبط وخلف بوابة.
- **غير مقرر:** لا يُبنى منه إلا التصميم والتقييم، دون تفعيل.

## 2. ما يتغير في سياسات الوثائق السابقة

- **«وحدة بدينار»:** لم تعد السياسة العامة. لكن البيانات التاريخية والطلبات القائمة تبقى بقيمها، ولا يُعاد حساب أي لقطة.
- **العمولة:** 10% خط أساس مبدئي وليس قانونًا نهائيًا. تغييرها يحتاج تغيير سياسة مخوّلًا ومسجلًا.
- **«أكثر من سوق نشط» في الإعداد التطويري** (JO وKW وSA): ليس تفعيلًا تجاريًا. بعد W09 تصبح الأسواق مقيّدة بدرجات التفعيل الصريحة.

## 3. حدود التفويض (من الأمر نفسه)

**مسموح:**
- التطوير وإعادة الهيكلة الآمنة.
- الاختبار والتوثيق.
- الـcommit ورفع فروع معزولة.

**غير مسموح دون موافقة صريحة منفصلة:**
- الدمج في `main`.
- النشر للإنتاج.
- تفعيل مال حقيقي أو ذكاء مدفوع.
- التواصل مع موردين حقيقيين.
- بيانات الإنتاج.
- إعلان الامتثال القانوني.

## 4. أسئلة مفتوحة للمالك (تتراكم مع الموجات)
