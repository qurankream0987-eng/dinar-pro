# DINAR — مقارنة جاهزية Gemma 4

**تاريخ مراجعة metadata العامة:** 2026-10-24  
**الحالة:** `FREE_PROVIDER_LIVE_TEST_NOT_RUN` · `MODEL_INTELLIGENCE_NOT_YET_VERIFIED`

هذه مقارنة توافق هندسي لا مقارنة جودة. لم يُرسل أي prompt إلى نموذج. لا يمكن استنتاج الفهم العربي أو اللهجات أو جودة اختيار الأدوات أو الكمون الحقيقي من metadata أو محاكاة محلية.

|---|---|---:|---|---|---|

| Gemma 4 31B IT | `google/gemma-4-31b-it:free` | $0 لكل prompt/completion token في metadata | `tools` و`tool_choice` مدعومان | 262,144 / 32,768 | قابل للتقييم بعد تحقق metadata وخصوصية الحساب |

كلاهما يقبل Chat Completions؛ DINAR تستخدم `tool_choice=auto` لتجنب فرض الأداة على سؤال عام. لا نعتمد على JSON Schema مفروض لدى المزود: التحقق المحلي بـZod يبقى إلزاميًا. OpenRouter model metadata لا يضمن أن كل endpoint متاح للحساب أو يضمن الاحتفاظ صفرًا؛ كلا الأمرين حاجز قبل الاختبار الحي.

## مقارنة OpenAI المرجعية

يوجد harness منفصل سابق لمرشحي OpenAI، لكنه يقيس نماذج مدفوعة. لا تُستدعى هذه النماذج في نطاق هذه الدفعة ولا تُضم إلى تشغيل Gemma. أي مقارنة مباشرة لاحقة تحتاج موافقة منفصلة وميزانية صريحة، ولا يجوز وصفها بأنها مجانية. المقارنة الحالية على الورق فقط: OpenRouter يشير إلى أسعار صفرية ويدعم الأدوات، بينما عقد OpenAI يملك أسعارًا موجبة وحجزًا ماليًا موثقًا في تقرير المقارنة السابق. لا توجد نتيجة جودة حقيقية لأي طرف هنا.

## معايير تقييم النموذج الحي مستقبلًا

يستخدم التشغيل الحي لاحقًا المهام الاصطناعية المشتركة في harness:

- الفصحى واللهجات الخليجية والشامية والمصرية والعراقية.
- سؤال عام لا ينبغي تحويله إلى بحث تجاري، وبحث/مقارنة بعناصر اصطناعية.
- وسائط أداة صحيحة وتحقق Zod، إحالة إلى نتائج/سياق سابق، وعدم اختلاق بيانات أو تنفيذ.
- حقن تعليمات في سجل المحادثة ووصف بائع اصطناعي.
- فائدة الرد، العربية، فهم المهمة، اختيار الأداة، دقة الوسائط، الاستمرارية، grounding، السلامة، وقياس latency.

القياسات البنيوية آلية؛ جودة اللهجة والفائدة تحتاج تقييمًا بشريًا أعمى. لا يُختار نموذج افتراضي من ادعاءات تسويقية أو من التوافق وحده.

## الاستضافة الذاتية والاقتصاد

Gemma 4 26B A4B نموذج MoE بحجم إجمالي معلن يقارب 25.2B ومع تفعيل 3.8B لكل token؛ Gemma 4 31B كثيف بحجم يقارب 30.7B. هذه أحجام المعلمات لا تكفي لاشتقاق احتياج VRAM الفعلي: يلزم تحديد checkpoint والكمّية، KV cache لطول السياق، runtime، batch/concurrency، ومعدل throughput مقاس. لم تُنزّل أوزان ولم تُحجز GPU.

| الخيار | ما يمكن قوله الآن | ما ينقص لاتخاذ قرار |
|---|---|---|
| A — OpenRouter المجاني | مناسب لتجربة اصطناعية محدودة إذا بقيت الأسعار صفرًا والحصة متاحة؛ لا SLA أو ضمان استمرار مستنتج هنا | تحقق حصة الحساب، retention/processing، توافر endpoint، وتجربة فعلية |
| B — استضافة مدفوعة | لا يوجد تقدير كلفة موثوق دون سعر مستضاف وthroughput مقاس | عروض موثوقة، كمون/إنتاجية تحت حمل DINAR، DPA وحدود إنفاق |
| C — استضافة ذاتية | قد تكون مناسبة لحجم مستمر، لكن لا دليل الآن على ملاءمة Railway العادي أو Replit CPU لتشغيل النماذج بكفاءة | GPU provider quotes، قياس VRAM/KV cache، autoscaling، التشغيل والمراقبة والتحديثات |

**نقطة التعادل غير محسوبة:** لا توجد عروض بنية تحتية أو بيانات أداء مقاسة. لا provisioning ولا تنزيل أوزان ضمن هذه الخطة. Gemma مرخصة Apache 2.0 بحسب صفحات OpenRouter، ويجب مراجعة شروط الإصدار/الأوزان الفعلية قبل أي استضافة.
