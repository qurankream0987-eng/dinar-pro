## 2. Code and API map

**Database: migration `0061_driver_location_sharing`** (additive, reviewed; in the manifest and the clone guard)
- New table `driver_location_shares`:
  - **one row per courier assignment (primary key `assignment_id`), holding only the latest position**;
  - a partial unique index allows one ACTIVE session per order;
  - CHECK constraints refuse coordinates on an ENDED row and bound ranges and accuracy.
- `transaction_locations`: source `MAP` allowed (with no accuracy figure).

**Server**
- `artifacts/api-server/src/lib/driver-location.ts`: start (consent), update, stop, `endLocationSharingForOrder`, sweep, and `firstPartyTrackingProvider`.
- Hooks:
  - `delivery.ts` (release assignments, handoff, settle);
  - `driver.ts` (admin revoke, suspension release).
- `app.ts`: registers the provider, gated by `DINAR_DRIVER_LOCATION_SHARING`.
- `index.ts`: runs the sweep every 60 s.
- `order-tracking.ts`: adds a buyer-only `destination`.

**HTTP**
- Driver-only, no-store, assignment-bound:
  - `GET  /api/courier/orders/:id/location-sharing`
  - `POST /api/courier/orders/:id/location-sharing/start` with `{ consent: true }`
  - `POST /api/courier/orders/:id/location-sharing/location` with `{ latitude, longitude, accuracyMeters, observedAt, sequence }` → 202 / 409 / 429 / 422
  - `POST /api/courier/orders/:id/location-sharing/stop`
- Buyer reads only through the existing `GET /api/orders/:id/tracking`.
- OpenAPI updated; clients regenerated by codegen.

**Web**
- `features/maps/DinarMap.tsx`: lazy MapLibre with real markers only, an honest fallback, a synthetic label, and reduced-motion support.
- `features/maps/map-style.ts`: reads `VITE_DINAR_MAP_STYLE_URL` (an https style URL or an inline test style).
- `features/ai/OrderTrackingSurface.tsx` («متابعة التوصيل»):
  - map with driver and destination markers;
  - last-update age and a STALE label;
  - polling only while tracking can change, never in a hidden tab.
- `features/ai/DeliverySurface.tsx`: «اختيار على الخريطة», «تعديل النقطة على الخريطة», and a map preview; coordinates are never printed or put in links.
- `features/ai/driver-location-sharing.ts`: the only `watchPosition` in DINAR.
  - Foreground only, at most one fix every 5 s, latest fix wins.
  - One shared session per order on the page; it stops when no control is visible.
- `features/ai/DriverLocationSharingControl.tsx`: explicit consent, an always-visible indicator, and a stop button.

## 3. Map provider comparison (prices from current public pages; confirm before buying)

| | MapLibre GL JS | MapTiler Cloud | Mapbox | Google Maps Platform | OSM public tiles |
|---|---|---|---|---|---|
| What it is | open-source renderer (no data) | tiles, styles, geocoding | tiles, SDK, geocoding, directions | tiles, Places, geocoding, Routes with traffic | community tile server |
| Cost | free (BSD) | free plan **non-commercial only**; commercial plans paid (quotes start around $25/month; confirm) | 50k free web map loads/month, then about $5 per 1k; geocoding and directions have free tiers | per-SKU free calls (Essentials 10k, Pro 5k, Map Tiles 100k), then paid | free, but **heavy or commercial-app use is forbidden without permission** |
| Arabic / RTL | renders Arabic labels from the style (RTL text plugin may be needed for some glyph sets) | Arabic label styles available | Arabic labels | strongest Arabic data and search | Arabic from OSM data |
| Jordan / Kuwait | depends on the data source | OSM-based | OSM-based + own data | best POI and address coverage | OSM coverage |
| Routing / ETA | none | none (per a competitor's claim) | Directions API (no traffic on base tier) | Routes API with live traffic | none |
| Key security | none | domain-restricted public key | URL-restricted public token | key restriction by HTTP referrer and API | none |

**Recommendation**
1. **Display:** keep **MapLibre GL JS** (already built). Point `VITE_DINAR_MAP_STYLE_URL` at a **commercial-licensed** style:
   - MapTiler paid, or Stadia; Mapbox styles also work through MapLibre only with their licence terms.
   - Never use `tile.openstreetmap.org` for production traffic.
2. **Geocoding and routing:** decide only when needed.
   - For Jordan/Kuwait landmark search and traffic-aware ETA, **Google** (Places + Routes) is the most accurate. It costs money above the free calls.
   - The display provider and the geocoding/routing provider are separate decisions. DINAR keeps them separate.
3. **Cost estimate for staging:** USD 0. The free/dev tiers of these providers cover test traffic. MapTiler free tier is for R&D only.
   - The first commercial month depends on map loads. At 50k loads/month, Mapbox costs about $0; a MapTiler commercial plan is a fixed fee.
   - These are estimates from public pricing pages, not quotes.

## 4. Security and privacy review

| Requirement | How it is met | Evidence |
|---|---|---|
| Explicit driver consent | `consent: true` required (400 otherwise); consent text lists scope; `consented_at` stored | suite 2, browser |
| Bound to one assignment and order | actor must be the ACCEPTED assignment's driver, same market; 404 for everyone else | suite 2, browser |
| Buyer-only reading | existing participant check; seller gets no coordinates; other users get 404; no-store | suite 3, browser |
| Anti-replay / out-of-order | strictly increasing `sequence`; older `observedAt` refused | suite 4 |
| Rate limit | 4 s minimum between accepted fixes (429 with Retry-After); the client sends at most every 5 s | suite 4, browser |
| Timestamp and value validation | future (>30 s) or old (>120 s) fixes, accuracy over 5 km, (0,0), out-of-range and >250 km/h jumps are refused | suite 5 |
| Stale ≠ live | fixes over 90 s old are served as STALE and drawn grey | suite 6 |
| Stops when it should | driver stop, handoff, settle (completed or cancelled), cancel/fail, admin revoke, suspension release, 15-min idle; the DB refuses coordinates after end | suites 7–10, browser |
| No history | one row per assignment, overwritten; ended rows hold no coordinates and are deleted after 30 days | D19 guard, suite 10 |
| No leakage in chat or logs | coordinates never written to messages, audit or logs; fallback UI prints no coordinates or links | suite 3, D16 log scan |
| Off unless enabled | outside development `DINAR_DRIVER_LOCATION_SHARING=enabled` is required (503 otherwise) | suite 11 |
| No background claim | the web shares only while the page is visible, and pauses with an explicit message | `driver-location-sharing.ts` |

Not done:
- **Native background location** (iOS "Always", Android foreground service) needs a native app, outside this web codebase.
- **Notifications** reuse the existing order and delivery events; no new paid SMS was added.
