**(أ) حاجز تشغيلي الآن:** دقائق GitHub Actions على الحساب نفدت/فشلت فوترتها. الإرسالان المطلوبان لإثبات العيب الخامس (`41877578228` منفرد، `41877681772` سلسلة) **لم يبدأ تشغيلهما**؛ annotation الحرفي: «The job was not started because recent account payments have failed or your spending limit needs to be increased». نقطة `user/settings/billing/actions` تُرجع 404 لهذا الـtoken فلا أقرأ الرصيد. **لا يمكن تحريك أي دليل قبول جديد قبل حلّها** — ولا يجوز إعلان `G2-36B` مُصلَحًا قبل `✔` فعلي.
