## الأداء وواجهة Replit

- خط أساس أقدم في `DINAR_PRO_WEB_LAUNCH_MASTER_PLAN.md`: بناء API 2.3 ثانية، بناء الواجهة قرابة 10 ثوانٍ، typecheck 9 ثوانٍ، ترحيل قاعدة فارغة 4.3 ثوانٍ، RSS قرابة 164MB، وطلب واحد لـ`/api/markets` قرابة 9ms. هذه قياسات منفردة/قديمة وليست اختبار حمل.
- سجل Command E: 96 حالة عبر 8 عروض ووضعي إضاءة؛ overflow والعناصر المجهولة وأهداف اللمس الصغيرة وأخطاء console كلها صفر. سجلت العينة JS=237 kB وCSS=37 kB transfer وDOMContentLoaded=246ms وظهور أول إجابة=1092ms؛ لا p50/p95 ولا ادعاء بأداء إنتاجي.
- لا قياس حديث لـCPU/RSS تحت حمل أو خطط استعلام DB أو تعافٍ بعد restart.
- معاينة 390px وسطح المكتب تُظهر واجهة RTL. طرف إحدى شرائح البداية يبدو مقصوصاً في لقطة 390px؛ لم يُختبر سحبها أو لمسها، لذا يحتاج التحقق في قبول تفاعلي.
- واجهة API في البيئة الحالية غير جاهزة: `readyz` يعيد 503 بسبب `migrations=pending`. سُجل أيضاً خطأ `42P01` عند محاولة AI في سجل التطوير، بما يتفق مع انحراف المخطط. لم تُطبق ترحيلات ولم تُعدّل قاعدة التطوير.

## العوائق المتبقية

### P0

1. **اعتماد GitHub التاريخي:** النمط ما زال في التاريخ القابل للوصول؛ المالك لم يؤكد الإبطال. لا نشر للمصدر.
2. **مزود تحقق الهاتف:** المحول التجريبي لا يرسل SMS حقيقياً؛ التسجيل/دخول الإدارة في Staging يحتاج مزوداً وقرار البلدان.
3. **تخزين الملفات:** محول S3 اجتاز اختباراً محلياً، لكن bucket واعتمادات كل بيئة غير موجودة.
4. **الموافقة القانونية والخصوصية والاحتفاظ:** لم تعتمدها جهة مختصة.
5. **بيئة التطوير الحالية:** ترحيلاتها معلّقة؛ لا تُصلحها في قاعدة التطوير ضمن هذه المهمة.
6. **اختيار سوق الإطلاق:** يلزم قرار المالك والسعر وسوق المدير الأول قبل تفعيل سوق واقعي.

### P1/P2

- DeepSeek الحقيقي: آخر قياس تاريخي 3/6 مطابق للعقد و3/6 مرفوض بأمان؛ لا تُستخدم صلاحيات الاختبار المستنفدة. جودة الإنتاج غير مثبتة.
- الدفع: لا مزود حقيقي؛ المحاكاة لا تثبت التحصيل أو التسوية أو الاسترداد.
- لا اختبار حمل اصطناعي حديث ولا p95.
- موثوقية DS-15 المتقطعة غير محسومة رغم عدم إعادة إنتاجها في 26 محاولة.
- اختبارات Chromium لا تغطي كل السيناريوهات A–J ولا كل المقاسات 320/390/768/desktop لكل رحلة.
- النسخ والاستعادة، المراقبة والتنبيهات، استعادة كلمة المرور، وقناة دعم ذات SLA لم تُغلق حسب خطة الإطلاق.
- مسح الاعتماديات بعد تحديث body-parser وundici وfast-uri ما زال يجد Zod 3.25.76 بدرجة عالية؛ الإصلاح المتاح Zod 4.6.6 يتطلب ترقية major واسعة لم تُنفّذ لتجنب كسر العقود ومخططات Drizzle.
