# قبول الإغلاق الهندسي النهائي — DINAR

**التاريخ:** 2026-10-23  
**النطاق:** تحقق هندسي محلي من الحالة الحالية، دون نشر أو دفع إلى GitHub.

## النتيجة

**القبول الهندسي: جزئي.** أُغلقت مجموعة اختبار واجهة متقادمة، وأُصلحت قابلية كتابة الرسائل عند 320px وتداخل شريط التنقل العائم مع المحتوى أثناء التمرير. نجحت مجموعات التحقق المسجلة أدناه. تبقى بنود واجهة/منتج جزئية وموافقات إطلاق خارجية؛ لذلك لا يعني هذا التقرير أن DINAR جاهز لإطلاق تجاري.

## التغييرات المحلية

- في الشاشات حتى 360px، ينتقل حقل الرسالة إلى صف كامل وتبقى أدوات الإرسال في صف منفصل؛ أُضيف فحص حد أدنى لعرض الكتابة يبلغ 160px.
- في الشاشات حتى 1023px، أُضيف مسار علوي معتم تحت زر سجل المحادثة العائم. السبب المؤكد كان بقاء الزر الشفاف فوق مساحة المحادثة القابلة للتمرير؛ كانت بطاقة المحادثة تمر بصريًا خلفه.
- أُزيل اختبار `premium-ui-acceptance.mjs` المتقادم بعد توثيق بدائله في تقرير الواجهة وسجل التنفيذ. البدائل هي اختبار تجربة المحادثة، واختبار إغلاق الواجهة، ومجموعات G3/Block الخاصة بالتدفقات المجالية. هذه التغطية ليست اختبار E2E موثّق الدخول.
- استُعيدت من الاختبار المتقاعد assertions ذات القيمة في اختبار الإغلاق الحالي: حالات زر DINAR المشتركة، وثبات موضع القراءة/تحميل الأقدم، وتقليل الحركة، وثيم صفحة السياسات المستقلة. لم يُعَد إنشاء harness القديم.
- استُعيد أيضًا سلوك الاختبارين المتبقيين في اختبار المتصفح الحالي: منع الإرسال عند انقطاع الاتصال مع الاحتفاظ بالمسودة، ومحاذاة العنوان/الأيقونة في مكوّن البطاقة المشترك عبر 16 عائلة مسماة.
- لم تُغيّر صلاحيات الدفع أو التسوية أو المزودات الحية، ولم تُجرَ تغييرات على خادم الإنتاج أو قاعدة البيانات المُدارة.

## ما بقي قبل الإطلاق

- تأكيد المالك المستقل بإلغاء صلاحية اعتماد GitHub التاريخية المكشوفة؛ لم تُطبع القيمة ولم تُستخدم.
- مراجعة قانونية ومالية لاختيار أسواق الإطلاق والمزود المرخص وحدود المدفوعات والتسوية.
- اختيار وتفعيل مزودات AI وSMS والدفع والخرائط والتوصيل الحية وإجراء تحقق مالك مصرح به.
- تأكيد المالك لاستعادة النسخ الاحتياطية وPITR في Railway؛ لم يُجرَ استعادة أو تغيير على قاعدة مُدارة.
- اكتملت لقطات أجسام ممثلة لعائلات الطلبات، حالة الطلب، التتبع، أجرة المندوب، مركز الخصوصية وتصدير البيانات؛ ما زالت المراجعة المرئية لكل حالة ولكل renderer متخصص غير مكتملة.
- لم تُنقل بعض العائلات المتخصصة إلى الإطار المركّب؛ النقل ليس شرطًا لهذه الجولة، وما زالت أدلتها البصرية الكاملة خارج نطاق المصفوفة.
- صورة المرجع «DINAR Cards — Examples» غير متاحة. الاشتراك والدفع وشركات الشحن والخرائط ومزودات AI/SMS الحية ما تزال خارج التحقق المحلي.
- لا يُتخذ قرار قانوني أو قرار إطلاق ضمن هذا العمل.

## جاهزية النقل وتسليم التكاملات

- **ما يمكن نقله كما هو:** خادم الويب والـAPI يقرآن `PORT`، ويدعم بناء الويب `BASE_PATH`، كما أن إعداد Vite يسمح بتحديد وجهة API عبر `API_PROXY_TARGET`.
- **جاهزية التخزين:** Replit sidecar باقٍ كافتراضي، وأُضيف محول S3-compatible اختياري مع تحقق بدء تشغيل واختبارات fixture محلية. لم تُختَر وجهة أو بيانات اعتماد، ولم يُنشأ bucket أو تُنقل ملفات؛ يلزم اختيار المالك واختبار staging وخطة تحقق/نقل قبل Railway.
- **تسليم المالك قبل أي تكامل حي:** (1) إلغاء أي اعتماد GitHub تاريخي مكشوف؛ (2) اختيار أسواق الإطلاق بعد المراجعة القانونية والمالية، بما في ذلك قواعد الدفع والتسوية؛ (3) اختيار مزودي AI وSMS والدفع والخرائط والتوصيل وتفويض اختبارهم؛ (4) تأكيد وجهة النسخ الاحتياطية واختبار الاستعادة وPITR في Railway؛ (5) اعتماد وجهة تخزين الملفات وسياسة الاحتفاظ وخطة نقلها؛ (6) تجهيز نطاقات ومفاتيح الجلسة/المزودات ومسارات OAuth عبر تدفق الأسرار، لا عبر المستودع.
- **لم يحدث في هذه المرحلة:** لا تكامل حي أو اعتماد مدفوع، ولا نقل بيانات أو تخزين، ولا تعديل لـRailway أو DNS أو أسرار، ولا نشر أو دفع إلى GitHub. يحتاج النقل اللاحق إلى اختبار مصادقة/جلسات ونطاقات ومصادر البيانات بعد إقرار المالك.

## حدود التنفيذ

لم يحدث دفع إلى GitHub، أو نشر، أو تشغيل مدفوعات حقيقية، أو استخدام خدمة مدفوعة، أو ترحيل/استعادة/حذف بيانات قاعدة مُدارة. نُفذ اختبار القبول على قاعدة PostgreSQL مؤقتة مربوطة بالحلقة المحلية ثم أُوقف خادمها.
