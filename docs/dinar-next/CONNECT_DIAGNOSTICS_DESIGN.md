# Read-only integration diagnostics and safe observations — design before implementation

Parent `34bb754d60617fbb49c26e6f1726f141234c8598`. Reuse existing partner ownership/independent ADMIN authority, canonical provider connection namespace, append-only Connect audit and ingestion receipts. Human staff retains catalog/reports-only access and receives no integration/key diagnostics. No outbound health probe, credential mutation, financial decision or new action runtime.

Provide bounded, stably paginated owner/admin diagnostics showing reviewed integration/site states, verification expiry, whether a source is configured, aggregate catalog status/freshness, incoming credential count and last successful ingress, last accepted catalog receipt time and sanitized observed sync outcomes. Present these as observations, never proof of live provider availability. Do not decrypt/expose OAuth tokens, hashes, fingerprints, raw audit detail, external payloads/URLs, customer identifiers or model/chat content. Keep current owner OAuth inspection in its existing service.

Record only already-authorized, admitted catalog sync attempts, after network/commit work and outside all network-held DB locks. Append a bounded safe outcome/reason and measured duration; never store provider messages, URLs, tokens, authorization headers or raw exceptions. Unauthorized/pre-admission/rate-denied calls must not generate audit-write amplification. Failure to append diagnostics must not turn a committed catalog receipt into a false operation failure; emit a sanitized operational warning and retain health uncertainty. Recheck ownership before appending.

Audit visibility returns selected immutable fields only. Review signals must be factual (e.g. recorded protected-response refusals, suspension events, current disputes/recovery obligations), not invented fraud verdicts or claims of comprehensive detection. API uses existing market scoping and no-store responses. Tests cover owner/admin/foreign/staff boundaries, cursor isolation, secret redaction, bounded pagination, live-health uncertainty, safe timeout/redirect observations, revocation races and unchanged financial/legal protections. Measure actual local query/response performance and preserve any external/provider acceptance blockers.
