# DINAR — سياسة العمولة والاسترداد (مسودة هندسية، W07–W08)

**الحالة:** 2026-10-30.
- مسودة هندسية **غير معتمدة قانونيًا**.
- العمولة **10% مؤقتة**، وقابلة للتعديل من الخادم (قرار المالك 6).
- لا مال حقيقي.

## 1. العمولة

| القاعدة | الحالة في الكود |
|---|---|
| النسبة من الخادم فقط، ولا تُقبل من العميل | ✅ `PLATFORM_FEE_BASIS_POINTS = 1000` في `lib/market-pricing.ts` |
| تُثبَّت على الطلب عند الشراء، ولا تُعاد حسبتها | ✅ `order.commissionRateBps` |
| بالوحدات الصغرى للعملة، وتقريب نصف لأعلى، ونطاق 0–10000 bps | ✅ `calculatePlatformFeeMinor` |
| عملة الطلب = عملة السوق. لا تحويل تلقائي، ولا KWD افتراضيًا | 🟡 `MARKET_CURRENCY = "KWD"` بقايا API قديم في الذاكرة. الطلبات تستخدم عملة السوق. **يُزال في W07** |
| النسبة لكل سوق أو فئة أو بائع | ⬜ W07: جدول إعداد مُرقّم بتاريخ سريان. الطلبات القديمة تبقى على لقطتها |
| دين العمولة على البائع | 🟡 `createSellerDueForOrder` عند الاكتمال. دفتر كامل في W07 |

### دفتر العمولة (W07)

قيود append-only لكل طلب، كل قيد بمفتاح idempotency، وتُحسب الأرصدة من القيود لا من حقل قابل للتعديل:

| القيد | المعنى |
|---|---|
| `ORDER_VALUE` | قيمة الطلب من اللقطة |
| `SELLER_AMOUNT` | قيمة الطلب ناقص العمولة |
| `COMMISSION_ACCRUED` | العمولة عند حدث الاستحقاق (👤: الاكتمال أم الدفع أم التسليم) |
| `PROVIDER_FEE` | رسوم المزود (في B) |
| `TAX` | 👤 أساسها غير مقرر |
| `COMMISSION_REVERSED` | عكس كامل أو جزئي عند الاسترداد |
| `COMMISSION_INVOICED` / `COMMISSION_PAID` | فوترة الدين وسداده (في A) |
| `CHARGEBACK` | من المزود (في B) |
| `ADJUSTMENT` | تصحيح بسبب وموافِق، ولا يحذف قيدًا |

**يُميَّز بوضوح بين:**
- «مكتمل»: الطلب.
- «مدفوع»: المال.
- «عمولة مسوّاة»: الدين.

## 2. الاسترداد

### القواعد الثابتة (مُطبّقة)

- **الدفع على طلب ملغى أو منتهي الحجز ليس بيعًا:**
  - يُنشأ التزام استرداد **واحد** (`payment_refund_obligations`).
  - الجدول append-only بقادح.
  - حالة النية `SIMULATION_BUYER_REFUND_DUE`.
- **لا يُلغى طلب مدفوع (مع تحرير المخزون) دون استرداد.**
- **لا شيء يعلّم المال مستردًّا إلا `REFUND_SUCCEEDED` موقّع من المزود.**

### مسار البطاقة (B)

1. طلب الاسترداد (كامل أو جزئي) من الطرف المخوّل، أو التزام D3.
2. الطلب يُرسل للمزود بمفتاح idempotency.
3. الحالة `REFUND_PENDING`.
4. حدث المزود الموقّع `REFUND_SUCCEEDED`، فـ`COMMISSION_REVERSED` بنسبة المسترد.
5. `REFUND_FAILED` يبقي الالتزام مفتوحًا ويُصعَّد.

### مسار النقد (A) — صادق، بلا ادعاء

DINAR **لا يستطيع** إعادة نقد لم يستلمه. لذلك:
1. الاسترداد التزام على **البائع**، ويوثّقه DINAR.
2. البائع يسجل الإعادة **بدليل** (صورة إيصال أو تحويل).
3. المشتري يؤكد الاستلام أو يعترض.
4. عند الاعتراض: نزاع بأدلة، ومراجعة بشرية، وإجراء على حساب البائع (W10).
5. لا تظهر للمشتري عبارة «تم الاسترداد» قبل تأكيده أو قرار النزاع.
6. عكس العمولة يتبع النتيجة المؤكدة فقط.

### الكويت (غير مؤكد قانونيًا)

ورد في البحث الأولي:
- حق إرجاع خلال 14 يومًا.
- سقف عمولة مُبلغ عنه: 10% لتوصيل التاجر، و17% لتوصيل المنصة.

لا يُبنى على هذا قبل مراجعة محامٍ (`docs/legal/COUNTRY_ACTIVATION_MATRIX.md`).
